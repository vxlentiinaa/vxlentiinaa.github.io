Poemas que aparecen en espiral.

sPIral es un dispositivo interactivo que muestra haikus en una pantalla OLED. A través del giro de un potenciómetro, el usuario recorre tres fases: el poema en espiral, el nombre del autor y un dibujo que lo representa.

Cada integrante del grupo buscó su propio haiku y pictograma, compartiendo la misma estructura de código pero con variaciones en el contenido textual y gráfico.

⊹ basado en la espiral logarítmica r = a · bᶿ

// fases de interacción

FASE 01
poema en espiral

Al girar el potenciómetro a la primera posición, las letras del haiku aparecen progresivamente siguiendo una espiral logarítmica desde el centro de la pantalla.

FASE 02
nombre del autor

En la segunda posición se muestra el nombre del autor del haiku, centrado en la pantalla OLED.

FASE 03
dibujo representativo

En la tercera posición aparece un dibujo diseñado por cada integrante que representa visualmente el contenido del poema, usando arrays de bits con drawBitmap.

// la fórmula del espiral

r = a · bθ
Espiral logarítmica donde r es la distancia desde el centro al origen.
Cada letra del poema se posiciona calculando sus coordenadas x e y:
x = centroX + radio · cos(ángulo)
y = centroY + radio · sin(ángulo)
El ángulo y el radio aumentan en cada letra, creando el efecto de espiral.

// etapas del código

// librerías necesarias
#include <Wire.h>         // comunicación entre dispositivos
#include <Adafruit_GFX.h>   // dibujar líneas, círculos y letras
#include <Adafruit_SSD1306.h> // manejar pantallas OLED pequeñas
#include <math.h>          // para cos() y sin() del espiral

// medidas de la pantalla
#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64
#define OLED_RESET -1
Adafruit_SSD1306 pantallita(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, OLED_RESET);

int potPin = A0; // pin del potenciómetro
// poema en espiral
String poema = "Noche de otoño… Se marchita el corazón, un espejo en la mano.";

float centroX = SCREEN_WIDTH / 2;
float centroY = SCREEN_HEIGHT / 2;
float angulo = 0;
float radio = 8;        // radio inicial
float pasoAngulo = 0.4; // avance angular por letra
float pasoRadio = 0.6;  // alejamiento del centro

// recorre letra por letra
for (int i = 0; i < poema.length(); i++) {
  char c = poema.charAt(i);
  int x = centroX + radio * cos(angulo); // posición X en la espiral
  int y = centroY + radio * sin(angulo); // posición Y en la espiral

  pantallita.setCursor(x, y);
  pantallita.write(c);
  pantallita.display();

  angulo += pasoAngulo; // avanza en la espiral
  radio += pasoRadio;
  delay(80); // tiempo entre letra y letra
}
// lectura del potenciómetro
int valor = analogRead(potPin); // valor entre 0 y 1023

if (valor <= 341) {
  // FASE 01 — mostrar poema en espiral
  dibujarEspiral();
}
else if (valor <= 682) {
  // FASE 02 — mostrar nombre del autor
  pantallita.setTextSize(0.3);
  pantallita.setCursor(0, 0);
  pantallita.println(mensaje);
  pantallita.display();
  delay(1000);
}
else {
  // FASE 03 — mostrar imagen representativa
  pantallita.drawBitmap(0, 0, hojassecas, 128, 64, WHITE);
  pantallita.display();
  delay(1000);
}
